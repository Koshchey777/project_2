# Проект Y
## Описание:

Виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Запустите PyCharm
2. В терминале введите
```
git clone git@github.com:Koshchey777/project_2.git
```
## Функции
+ `get_mask_card_number` - функция маскировки номера банковской карты
+ `get_mask_account` - функция маскировки номера банковского счета
+ `mask_account_card` - функция для маскировки номера или счета
+ `get_date` - функция преобразования даты в формат ДД.ММ.ГГГГ
+ `filter_by_state` - функция возвращает новый список словарей, содержащий только те словари,
    у которых ключ state соответствует указанному значению
+ `sort_by_date` - функция возвращает новый список, отсортированный по дате
+ `filter_by_currency` - функция возвращает итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной
+ `transaction_descriptions` - генератор, который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди
+ `card_number_generator` - генератор, который выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера карты
+ `reader_csv` - функция для чтения файлов формата csv
+ `reader_xlsx` - функция для чтения файлов формата xlsx
+ `process_bank_search` - функция возвращает список словарей, у которых в описании есть задаваемая строка
+ `process_bank_operations` - функция возвращает словарь, в котором ключи — это названия категорий
    а значения — это количество операций в каждой категории.

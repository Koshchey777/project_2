# Проект Y
## Описание:

Виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Запустите PyCharm
2. В терминале введите
```
git clone git@github.com:Koshchey777/project_2.git
```
## Функции
+ `get_mask_card_number` - функция маскировки номера банковской карты
+ `get_mask_account` - функция маскировки номера банковского счета
+ `mask_account_card` - функция для маскировки номера или счета
+ `get_date` - функция преобразования даты в формат ДД.ММ.ГГГГ
+ `filter_by_state` - функция возвращает новый список словарей, содержащий только те словари,
    у которых ключ state соответствует указанному значению
+ `sort_by_date` - функция возвращает новый список, отсортированный по дате
